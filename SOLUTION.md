# SMILES-2026 Hallucination Detection Solution

## Task summary

The task is binary hallucination detection for responses generated by
`Qwen/Qwen2.5-0.5B`. Each sample contains a ChatML `prompt`, a generated
`response`, and a label where `0` means truthful and `1` means hallucinated.
The solution must use the model hidden states, train a lightweight probe, write
`results.json`, and create `predictions.csv` for the unlabelled competition
`data/test.csv`.

## Approach

The implementation keeps the original repository entry points and public API:

- `solution.py` remains the main script.
- `aggregation.py` converts hidden states into fixed-size feature vectors.
- `probe.py` implements `HallucinationProbe` with `fit`, `predict`,
  `predict_proba`, and `fit_hyperparameters`.
- `splitting.py` returns one deterministic stratified train/validation/test
  split.

The final method is intentionally simple: multi-layer hidden-state pooling,
PCA dimensionality reduction, and balanced logistic regression.

## Model and features

The feature extractor uses the hidden states produced by `Qwen/Qwen2.5-0.5B`
for the concatenated text `prompt + response`.

For each sample, `aggregation.py` selects layers `-1`, `-2`, `-4`, and `-8`.
For every selected layer it concatenates three pooled vectors:

- the final real token representation,
- the mean representation over the final 64 real tokens,
- the mean representation over all real prompt and response tokens.

Qwen2.5-0.5B has hidden size 896, so the final default feature vector has:

`4 layers * 3 pools * 896 = 10752` dimensions.

`extract_geometric_features` is also implemented for optional use, but
`solution.py` currently leaves `USE_GEOMETRIC = False` to keep the submitted
baseline compact and reproducible.

## Probe

`HallucinationProbe` uses:

- `StandardScaler`,
- `PCA(n_components=96, random_state=42)`,
- `LogisticRegression(C=0.5, class_weight="balanced", max_iter=5000,
  random_state=42)`.

The validation split is used by `fit_hyperparameters` to tune the decision
threshold for F1. Probability outputs from logistic regression are used for
AUROC.

This linear baseline was chosen because the labelled dataset is small
(689 samples) and the hidden-state feature vector is high-dimensional. PCA
reduced overfitting compared with fitting logistic regression directly on all
features.

## Training procedure

`splitting.py` uses a deterministic stratified split:

- 70% train,
- 15% validation,
- 15% internal test.

The final competition probe is trained by `solution.py` on the union of the
training and validation indices and then applied to `data/test.csv`.

## How to reproduce

From a clean checkout:

```bash
git clone <your-repository-url>
cd SMILES-2026-Hallucination-Detection-Solution
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 solution.py
```

The first run downloads `Qwen/Qwen2.5-0.5B` from Hugging Face. A GPU, MPS, or
Colab T4 is recommended. On this local run, MPS was used and hidden-state
extraction for the labelled set took about 126 seconds.

Running `python solution.py` creates:

- `results.json`: internal split metrics and metadata,
- `predictions.csv`: two columns, `id` and `label`, for the 100 unlabelled test
  samples.

## Experiments and discarded attempts

The initial probe used balanced logistic regression directly on the full
10,752-dimensional hidden-state feature vector. It overfit the train split
strongly:

- train AUROC: 100.00%,
- validation AUROC: 68.85%,
- internal test AUROC: 62.70%.

Adding PCA before logistic regression reduced overfitting and improved the
internal test AUROC to 68.36%, so the PCA version is the final approach.

The optional geometric features in `aggregation.py` were implemented but left
disabled for the final run. They are useful for future experiments, but the
submitted baseline prioritizes a stable and easy-to-reproduce feature set.

## Limitations and possible improvements

This is a robust baseline rather than a heavily tuned solution. Potential
improvements include:

- cross-validation and ensembling across multiple stratified folds,
- tuning PCA dimensionality and logistic regression regularization,
- enabling and validating geometric features,
- response-only pooling based on exact prompt/response token boundaries,
- calibration or threshold selection optimized for the competition metric.
